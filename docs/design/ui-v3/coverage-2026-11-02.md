# Feature coverage: desktop v3 vs web, API and marketing (2026-11-02)

Read-only audit. Sources: `upforge-api/routes/api.php`, `upforge-frontend/app/pages/**` plus the pricing and marketing copy, the desktop router (`src/main.ts`), the v3 views and components, the preload IPC (`electron/preload/index.ts`) and `coverage.md`.
Branches: desktop `fix/desktop-audit-2026-11-02`, API `feat/upforge-score-and-audit-data`.

**Severity**
- **P1:** promised on marketing or pricing, but missing or near-unreachable in the app.
- **P2:** was in the classic UI, but is lost in v3.
- **P3:** web-only, and that is fine as long as the app links out.
- **P4:** nice to have.
